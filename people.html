사람들People

{%- comment -%} A map of the group rather than a list of it. Each field is a point, its members orbit it, and anyone working in two fields is drawn between the two -- which is where the interdisciplinary part of the group actually shows. Positions come from tools/build_graph.py, so this is a finished SVG: no layout library, nothing settling on load, same picture every time. Clicking a node fills the panel beside it rather than jumping down the page, so reading through the group does not mean scrolling back up each time. That is :target, so it needs no script. The list below is the real content; this is a way into it. The map is hidden from assistive technology, which gets the list, and from narrow screens, where a 22-node map is unreadable. {%- endcomment -%} {% assign g = site.data.people_graph %} {% if g %}
